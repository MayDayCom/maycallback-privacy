자동 응답 시작
어떤 기능을 배우나요?
✓

처음 설치한 뒤, 이 순서대로

문자 준비 → 조건 선택 → 자동 응답 시작. 세 단계만 먼저 완료하세요.

  1. 상단 ‘설정 도우미’ 아이콘을 눌러 전화·문자·알림 권한 확인
  2. 아래 ‘문자 관리’ 메뉴에서 ‘새 문자’ 만들기
  3. ‘언제 보낼까요’에서 수신완료·부재중·발신완료 중 원하는 방식 선택
  4. 홈으로 돌아와 사용할 자동 발송 스위치 켜기
  5. 상단 큰 카드의 ‘자동 응답 시작’ 누르기
꼭 확인

스위치만 켜고 ‘자동 응답 시작’을 누르지 않으면 작동 상태를 다시 확인해야 합니다.

✓

홈 화면에서 실제로 누르는 버튼

홈 위쪽 파란 카드에 전체 실행 버튼. 그 아래 자동 발송 종류별 스위치.

  1. ‘부재중’ — 부재중 전화 자동 회신
  2. ‘수신 통화 완료’ — 받은 전화가 끝나면 자동 문자
  3. ‘발신 통화 완료’ — 건 전화가 끝나면 알림에서 발송 선택
  4. 원하는 항목 스위치 켠 뒤 상단 ‘자동 응답 시작’ 누르기
  5. 멈출 때 ‘자동 응답 끄기’ 누르기
꼭 확인

전체 자동 응답 실행 중에는 각 항목 스위치 변경이 잠길 수 있습니다. 먼저 자동 응답 끄기.

✓

건 전화 이후, 직접 발송 선택

이 기능은 자동 전송이 아닌 ‘알림 방식’입니다.

  1. 문자 관리에서 발신완료 용 문자 저장
  2. 홈의 ‘발신 통화 완료’ 스위치 켜기
  3. ‘자동 응답 시작’ 누르기
  4. 발신 통화가 끝난 뒤 알림 확인
  5. 알림에서 직접 문자 발송 선택
꼭 확인

소스 안내 그대로: 실제 통화 연결 여부는 구분하지 않습니다.

✓

보낼 문자를 직접 만드는 방법

앱 하단 ‘문자 관리’ → 맨 아래 ‘새 문자’. 여기에 문구와 발송 조건을 한꺼번에 저장합니다.

  1. 하단 ‘문자 관리’ 선택 → ‘새 문자’ 누르기
  2. ‘이름’ 입력: 목록 구분용. 상대방에게 보내지지 않음
  3. ‘내용’ 입력: 상대방에게 보낼 실제 문구
  4. ‘언제 보낼까요’에서 부재중·수신완료·발신완료·사용안함 중 선택
  5. 필요하면 ‘발송 지연’ 선택 또는 ‘직접 입력’에서 초·분 지정
  6. 오른쪽 위 ‘저장’ 누르기
꼭 확인

‘사용안함’ 선택 시 문자만 저장. 자동 발송에는 사용하지 않습니다.

✓

사진 첨부 문자 작성

문자 수정 화면의 ‘이미지 (선택)’에서 사진을 붙일 수 있습니다.

  1. 문자 관리 → 기존 문자 누르기 또는 새 문자
  2. ‘이미지 (선택)’에서 사진 추가
  3. 사진 최대 3장 첨부
  4. 사진을 길게 누른 후 끌어서 순서 변경
  5. 이미지 첨부 시 ‘문자 제목’ 필요하면 작성
  6. ‘저장’ 누르기
꼭 확인

사진 문자는 MMS 처리 조건과 요금이 적용될 수 있습니다. 실제 발송 전 테스트 권장.

✓

기존 문구·발송 조건 바꾸기

문자 관리 목록에는 저장한 문자 제목·내용·발송 조건·지연·사진 개수가 표시됩니다.

  1. 하단 ‘문자 관리’ 선택
  2. 수정할 문자 카드 누르기
  3. 내용이나 ‘언제 보낼까요’ 조건 수정
  4. 오른쪽 위 ‘저장’ 누르기
  5. 홈 ‘보낼 문자’ 미리보기에서 적용 상태 확인
꼭 확인

발신완료 문자는 알림에서 확인한 뒤 직접 발송합니다.

자동 문자 제외 번호 관리
어떤 기능을 배우나요?
✓

그룹 만들고 단체 문자

발송 대상 탭 첫 번째 항목은 ‘그룹관리’입니다.

  1. ‘발송 대상’ → ‘그룹관리’
  2. ‘그룹 만들기’ 선택 후 이름 저장
  3. 그룹을 열고 ‘그룹원 추가’ 선택
  4. 연락처에서 선택 또는 이름·번호 직접 입력
  5. 필요하면 ‘그룹문자전송’ 또는 ‘예약문자전송’ 선택
꼭 확인

단체 문자·예약 문자는 자동 콜백과 다른 기능입니다. 대상 번호를 확인하고 전송하세요.

✓

특정 번호에 문자가 안 가게

연락처·개별 번호와 ‘번호 앞자리 규칙’을 지원합니다.

  1. ‘발송 대상’ → ‘발송 제외 목록’
  2. 개별 번호 추가: ‘직접 입력’ 또는 ‘연락처에서 선택’
  3. 이름(선택), 전화번호 입력 후 ‘추가’
  4. 앞자리 전체 차단: ‘번호 앞자리 규칙’에 예: 070 입력
  5. 등록된 제외 항목 확인
꼭 확인

앞자리 규칙은 일치하는 번호 전체에 적용될 수 있습니다. 테스트 전 반드시 확인하세요.

✓

문자가 왜 안 갔는지 확인

‘발송 기록’은 발송 요청 및 결과 확인용 화면입니다.

  1. ‘발송 대상’ → ‘발송 기록’
  2. 문자를 보낸 시각과 처리 결과 확인
  3. 문제 발생 시 SMS 권한, 제외 목록, 전송 금지 시간 확인
  4. 같은 번호 테스트라면 ‘설정 → 재발송 제한’ 확인
꼭 확인

앱 내 발송 완료 상태와 상대방 수신 확인은 다를 수 있습니다.

✓

문자를 보내는 유심 확인

앱 메뉴 이름: ‘듀얼 USIM 설정(BETA)’

  1. ‘발송 대상’ → ‘듀얼 USIM 설정(BETA)’
  2. 전화 권한 허용 및 ‘다시 불러오기’로 현재 회선 확인
  3. 콜백 발신에 사용할 USIM 선택
  4. 저장한 뒤 실제 전송 회선 시험
꼭 확인

BETA 기능. 제조사·Android·통신 환경에 따라 회선 선택이 제한될 수 있습니다.

메이콜백의 발송 규칙을 관리합니다.
어떤 기능을 배우나요?
✓

문자가 안 나갈 때 가장 먼저

설정 첫 번째 항목인 ‘설정 도우미’가 권한·알림·배터리 제한을 점검합니다.

  1. 하단 ‘설정’ → ‘설정 도우미’
  2. 화면의 미완료 항목부터 확인
  3. 필요한 권한에 ‘허용’ 또는 ‘설정’ 선택
  4. 시스템 설정 완료 후 앱으로 돌아오기
  5. 홈 ‘자동 응답 시작’ 후 본인 번호 시험
꼭 확인

전화 선별 앱 설정 등은 Android 버전과 기기에 따라 별도 승인 화면이 나올 수 있습니다.

✓

같은 번호로 반복 발송 막기

‘설정 → 재발송 제한’에서 간격을 선택합니다.

  1. ‘설정’ → ‘재발송 제한’
  2. 원하는 시간·기간 항목 선택
  3. 하단 ‘지금 설정’ 문구 확인
  4. 동일 번호 테스트 시 선택 기간 경과 여부 확인
꼭 확인

소스상 부재중·수신 완료·발신 완료에 같은 재발송 제한 기준 적용.

✓

밤·휴일엔 보내지 않기

메뉴 이름: ‘발송 시간·요일’. 상세화면: ‘발송 금지 시간·요일’.

  1. ‘설정’ → ‘발송 시간·요일’
  2. 발송하면 안 되는 요일 선택
  3. 발송 금지 시간대 지정
  4. 밤에 금지하려면 ‘밤 20~07시 선택’ 이용
  5. 전체 제한 해제 시 ‘모두 해제’ 확인
꼭 확인

전송이 안 되면 먼저 현재 시간·요일이 금지 구간인지 확인.

✓

긴 문자 MMS 설정

앱의 ‘발송 방식’ 메뉴는 긴 문자를 어떤 방식으로 보낼지 정합니다.

  1. ‘설정’ → ‘발송 방식’
  2. 긴 문자 처리 옵션 확인
  3. 요금제와 필요 기능에 맞게 선택
  4. 문자 관리에서 내용 확인 후 시험 발송
꼭 확인

실제 SMS/MMS 처리 및 요금은 통신사 환경에 따라 달라질 수 있습니다.

✓

휴대폰 변경 전에 준비

문자·사진·설정을 백업하고 복원합니다.

  1. ‘설정’ → ‘백업 / 복원’
  2. 백업 화면에서 파일 저장
  3. 저장한 파일을 안전한 장소에 보관
  4. 필요 시 복원 메뉴로 가져오기
  5. 복원 후 홈 자동 응답 상태·권한 다시 확인
꼭 확인

백업 파일에는 전화번호·문자 등 개인정보 포함 가능. 파일 공유 주의.

자주 묻는 질문

홈 스위치를 켰는데 문자가 안 가요.

상단 ‘자동 응답 시작’도 눌렀는지 확인하세요. 그다음 ‘설정 도우미’ 권한, 문자 관리의 발송 조건, 발송 제외 목록, 재발송 제한, 발송 금지 시간 확인.

발신 통화가 끝나면 자동 전송되나요?

아니요. 발신 완료는 알림 방식. 알림에서 직접 선택해야 발송됩니다. 연결된 통화인지 구분하지 않습니다.

사진은 몇 장까지 보낼 수 있나요?

문자 작성 화면 기준 최대 3장. 길게 누르고 끌어 순서 변경 가능.

테스트 문자가 계속 안 와요.

같은 번호에 대한 재발송 제한, 제외 목록, 현재 금지 시간, 권한, USIM 선택 순서로 확인하세요.
