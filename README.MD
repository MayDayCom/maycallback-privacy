
# 메이콜백 개인정보처리방침

메이콜백(MayCallBack) 앱의 개인정보처리방침 공개 저장소입니다.

## 공개 페이지

- 개인정보처리방침: https://maydaycom.github.io/maycallback-privacy/

## 앱 소개

메이콜백은 Android 통화 후 자동 문자 발송 앱입니다.

사용자가 설정한 조건에 따라 문자 발송 기능을 제공합니다.

## 개인정보 보호

- 개인정보 처리방침 공개
- 앱 데이터 처리 및 보관 안내
- 권한 사용 목적 안내
- 데이터 삭제 방법 안내

## 운영자

메이데이컴퓨터 (Mayday Computer)

## 문의

개인정보 관련 문의는 공개된 개인정보처리방침의 연락처를 확인하세요.
