# 메이콜백 (MayCallBack)

안드로이드 통화 후 안내 문자 발송 앱 **메이콜백**의 공식 안내 페이지 저장소.

## 바로가기

- [사용 설명서](https://maydaycom.github.io/maycallback-privacy/help.html) — 처음 설정부터 문자 발송까지
- [개인정보처리방침](https://maydaycom.github.io/maycallback-privacy/) — 권한 및 개인정보 처리 안내

## 주요 기능

- 부재중 전화 후 안내 문자 자동 발송
- 수신 통화 종료 후 안내 문자 자동 발송
- 발신 통화 종료 후 알림에서 사용자 선택 발송
- 문자 내용·발송 조건·지연 시간 설정
- 발송 제외 번호, 재발송 제한, 발송 시간·요일 관리
- 발송 기록 확인 및 백업·복원

## 처음 사용하는 방법

1. 앱 첫 실행 시 자동 표시되는 **설정 도우미**에서 권한 허용
2. **문자 관리**에서 안내 문자 작성
3. **발송 조건** 선택 후 저장
4. **홈**에서 해당 기능 활성화 및 **자동 응답 시작**
5. 시험 통화 후 문자 도착 및 **발송 기록** 확인

권한 허용이 막히면 [사용 설명서의 1단계](https://maydaycom.github.io/maycallback-privacy/help.html)에서 **제한된 설정 해결 방법**을 펼쳐 확인.
