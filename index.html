개인정보 처리방침

1. 앱이 하는 일

통화가 끝났거나 전화를 받지 못했을 때, 사용자가 미리 저장해 둔 문자(사진 포함)를 전화를 건 번호로 자동으로 보내 주는 앱입니다.

서버로 보내는 데이터가 없습니다.
앱은 인터넷 접속 권한이 없으며, 개인정보를 운영자나 다른 서버로 보내지 않습니다. 광고와 사용자 분석 도구도 사용하지 않습니다.

2. 사용하는 권한과 목적

권한목적
전화 (전화 상태)전화가 오고 끝나는 것을 알아냅니다.
통화 기록걸려 온 전화번호를 확인하고, 발송 제외 번호를 고를 때 최근 통화 목록을 보여 줍니다.
문자 보내기저장해 둔 문자를 자동으로 보냅니다.
연락처발송 제외 번호를 고를 때 연락처 목록을 보여 줍니다. 해당 화면을 열 때만 읽습니다.
알림앱이 동작 중이라는 표시를 위쪽에 보여 줍니다.
백그라운드 동작
부팅 후 시작
배터리 사용 제한 해제		앱을 닫거나 폰을 다시 켠 뒤에도 자동 응답이 계속 동작하게 합니다.

3. 앱이 다루는 정보

  • 걸려 온 전화번호, 시각, 발송 결과(발송 기록, 최대 200건)
  • 사용자가 만든 문자 내용과 첨부 사진
  • 사용자가 지정한 발송 제외 번호와 이름, 앱 설정값

이 정보는 모두 사용자의 폰 안에만 저장됩니다.

4. 외부 전송과 제3자 제공

  • 앱은 인터넷 접속 권한이 없으며, 개인정보를 운영자나 다른 서버로 보내지 않습니다.
  • 광고와 사용자 분석 도구를 사용하지 않습니다.
  • 통화 기록과 연락처는 위 2번의 목적 외에 사용하지 않고, 제3자에게 제공하지 않습니다.
앱의 기능상, 전화를 건 번호로 사용자가 저장한 문자와 사진이 통신사의 문자 서비스를 통해 전달됩니다. 이미지 문자는 폰의 MMS 기능이 모바일 데이터를 사용하며, 요금은 사용자의 통신사 요금제에 따릅니다.

5. 백업 파일

사용자가 앱의 백업 기능을 누르면, 문자, 사진, 설정, 발송 제외 번호와 이름이 하나의 파일로 사용자가 고른 위치에 저장됩니다.

이 파일은 암호화되지 않습니다.
앱이 외부로 보내지는 않지만, 파일의 보관과 공유는 사용자의 책임입니다. 폰의 기본 백업 기능(예: 구글 백업)을 사용 중이면 기기 설정에 따라 앱 데이터가 그 백업에 포함될 수 있습니다.

6. 보관과 삭제

  • 발송 기록 — 앱의 "발송 기록" 화면에서 전체 삭제할 수 있습니다. 최대 200건만 보관하며 오래된 기록은 자동으로 지워집니다.
  • 문자와 사진 — 문자를 삭제하면 그 문자에 붙인 사진 파일도 함께 삭제됩니다.
  • 발송 제외 번호 — 목록에서 삭제할 수 있습니다.

앱을 삭제하면 앱이 저장한 정보가 모두 지워집니다. 사용자가 따로 저장한 백업 파일은 직접 지워야 합니다.

7. 권한 철회

폰의 설정 → 앱 → 메이콜백 → 권한에서 언제든 권한을 끌 수 있습니다. 필요한 권한이 꺼져 있으면 자동 문자 기능이 동작하지 않습니다.

8. 아동의 개인정보

앱은 만 14세 미만 아동의 개인정보를 따로 수집하지 않습니다.
